# 故宫分级建筑资产

本资产基于项目缓存 OpenStreetMap 建筑、屋顶分部、水面和道路数据制作。平面位置、轮廓和已标注的屋顶坡向来自缓存；绝大多数众包高度未经核验，不能称为实测高度。曲面举折、瓦垄、脊饰、柱廊、石雕、植被及生成材质属于艺术重建，尚不能替代摄影测量、点云、专业测绘或文物建筑修复模型。

- 地理数据：[OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，ODbL 1.0。
- Blender 构建入口：`scripts/build_palace.py`，使用 Blender 5.2.1 LTS CLI。
- 原生文件：项目根目录 `故宫精细建筑.blend`，包含7区高细节主体及全部微瓦块，打包庭院石砖、琉璃釉色、树叶和汉白玉4张生成材质。
- `manifest.json` 是渲染块、包围盒、三角面数、字节数、官方校正记录与材质参数的唯一索引。

坐标原点为116.415°E、39.915°N，局部1单位=100米。Blender X向东、Y向北、Z向上，glTF/Three.js坐标为 `(east, height, -north)`。庭院Z=.008，结构表现基面Z=.011，水面Z=.004。应裁去覆盖范围内旧模型建筑及旧 terrain；旧起伏地形会盖住新水面。底座 base 可以保留。

7个主体区分别提供medium/high完整替换模型。建筑按中心分区，完整建筑可能伸出分区 bounds；中景7区加载完后整体替换旧城市，高景与同名中景独立替换，不应按分区矩形裁剪建筑。两级保留同一完整连续屋面、脊线及檐饰，不含低于屏幕采样尺度的瓦筒。主体每区通常12–15个材质批次。

全部瓦筒现位于 `manifest.microTiles`，包括主体0.5米、附属建筑0.4米间距的瓦垄。微瓦按约100米网格切分，超过16 MB的块再按完整屋面集合无损细分。只应在近景投影超过约300像素/100米时加载附近微块；微块未加载时，主体屋面仍完整存在。块数以清单为准，不可写死；每块一个共享 Roof_Glazed_Ochre 材质批次。瓦筒是近景装饰叠加层，不能替换主体块。

铺装UV按故宫轴线约1.37°旋转，单位为米。台基顶面拆为 Terrace_Paving，使用1.8×1.2米石板、2厘米接缝；顶面保持原结构标高，缝底仅下沉1.5厘米。Limestone保留白石立面、栏杆及石雕。庭院使用 Courtyard_Axis、Courtyard_Cool、Courtyard_Warm 三个连续冷暖灰铺装区，外围使用 Courtyard_Stone；这些是艺术材质分区，不表示额外道路。共享贴图与建议重复尺度见 `manifest.surfaceMaterials`。

瓦筒改为连续上半圆截面，主体6段、附属建筑5段半圆截面，封闭端面，按圆弧长与轴长展开UV。基础屋面在檐口高曲率处加密，避免粗弦面穿过瓦筒形成断续；取消逐面UV方向切换。所有瓦筒移出主体high，避免宏观视角的亚像素摩尔纹。

植物只位于映射绿地，171个树基位置和路径避让保持稳定。冠幅为艺术表现约10–19米，使用8条不对称主枝、分叉枝和20个相互覆盖的叶簇体积，每棵中景120张、近景360张叶簇卡。Foliage_Leaves使用共享foliage.png，UV为[0,1]，应设置双面和alphaTest，不采用米制重复。估算树冠与绿地相交面积约25,293平方米；它是种植外包范围估计，不是实测植被覆盖。

水面优先采用缓存面轮廓，仅对缺少面的地表明渠按缓存中心线补面；未标宽的水渠以4米作艺术估算，不显示地下或已盖板河段。灰石护岸沿缓存岸界生成，并依据20处缓存桥线恢复跨水桥梁，其中包含5座内金水桥；桥宽、拱面和栏杆是艺术重建。

## 太和殿高度及开间校正

[故宫博物院的太和殿介绍](https://www.dpm.org.cn/explore/building/236465.html)公布殿身26.92米、台基8.13米、连台基35.05米，面阔11间、进深5间。[故宫博物院所载相关文章](https://www.dpm.org.cn/Uploads/pdf/1602/T00092_00.pdf)区分至殿脊35.05米与包含吻卷尾37.44米的口径。核验日期为2026年9月13日。

本地OSM屋顶分部原有41米标高，与官方资料冲突，已不再直接沿用。模型以当前连接完整的9米台面为固定锚点，把太和殿木构和两层屋面一起按26.92÷32校正，名义屋面基准从41米调整为35.92米。下檐柱廊明确采用11开间、5进深；柱距等分仍是建模近似，未以历史图纸逐柱测定。下层柱廊落在原台面上，上层木构从下层屋面上方起，避免单独缩放殿身导致悬空。

三大殿共享的3/6/9米台基尚未统一重建为官方8.13米，所以名义总标高仍较官方通高多0.87米；35.92米是校正后的屋面基准，不能称为实测完成面高度。脊帽与吻兽等艺术装饰高于该基准，其细部仍未逐项按测绘资料校正。全场另有1.1米结构表现基面偏置，与历史建筑尺寸分开记录。相关差异及来源写入 `manifest.heightCorrections`，没有为追随AI概念图增造楼层、合并三大殿或挪动实际足迹。

更新后以清单统计为准。旧城区8K静态图不由本脚本重写。
